# exp_007: 忘却の機序分析（部分空間干渉と忘却の相関）

## 位置づけ
研究の主貢献は C3（手法・手法駆動）。本実験(C2 機序分析)は**手法設計の動機付け（supporting）**。
目的は2つ:
1. 提案手法（InfLoRA型 = 更新を過去/COCO の部分空間と直交させる）の**前提と妥当性を実証**する。
2. **どこに LoRA を入れ、何を直交対象にし、rank をいくつにするか**という設計判断の根拠を得る。

**すべて既存チェックポイントで実施し、再学習は行わない**（順伝播＋線形代数のみ）。
※ 本 design は妥当性レビュー（[[validity_review]]）の指摘を反映済み（trace ベース指標・座標系統一・交絡統制・因果ミニ検証）。

## 中核の問い
- **C: ドメイン i の更新が、過去ドメイン/COCO の重要部分空間に作用して出力を乱すか（干渉）。**
- **D: その干渉量が、実測した忘却量（exp_005/006）と相関するか。**
- **E: 干渉成分を直交除去すると忘却が実際に減るか（因果ミニ検証）。**
- 補助 A（局在化）・B（低ランク性）で手法設計（挿入箇所・rank）を裏付ける。

## 使用する資産（再学習なし）
- base（事前学習）: `grounding_dino_swin-t_pretrain_obj365.py` + 事前学習重み。
- 単独FT（凍結, exp_005/004）: 各ドメイン best ckpt。
- 逐次FT（exp_006）: `aerial→D2` の best ckpt（5本）＋ aerial 単独 ckpt（exp_005）。
- プローブデータ: 各ドメイン valid 画像 N=1000（少なければ全件）＋クラス名プロンプト。COCO は val2017 から N=1000。

## 理論的背景と干渉の定義（厳密）
線形層 `e = W h`。学習で `W_base → W_i`、更新 `ΔW_i = W_i − W_base`。
X のデータがこの層に入れる活性化を `H_X=[h_1,…,h_N]`（d_in×N）、共分散 `C_X = H_X H_Xᵀ`。
**この更新が X の層出力に与える摂動（同一入力前提）＝ `ΔW_i H_X`**。その大きさは恒等式で:
```
Interf_abs(i→X, ℓ) = ‖ΔW_i H_X‖_F² = trace(ΔW_i C_X ΔW_iᵀ) = Σ_j λ_j ‖ΔW_i u_j‖²
```
（`C_X = Σ_j λ_j u_j u_jᵀ` は固有分解。`‖A‖_F²=trace(AAᵀ)` より厳密に成立）
= 「ドメイン i の更新が X の層出力をどれだけ乱すか」＝**忘却の直接代理**（1層・入力固定の一次近似）。

**重要部分空間 S_X** = `C_X` の上位固有ベクトル（累積エネルギー95% or 固定 k）。GPM の M_t に相当。
※ 旧 design の `overlap(U,S)=‖UᵀS‖²/min(k)` は固有値 λ_j と更新の大きさを無視する粗い代理のため**不採用**。

## 干渉指標（3種、目的別）
| 指標 | 式 | 意味 |
|---|---|---|
| 絶対干渉 | `‖ΔW_i H_X‖_F²`（=trace(ΔW_i C_X ΔW_iᵀ)） | i の更新が X 出力を乱す量（忘却の直接代理） |
| 相対干渉 | `‖ΔW_i H_X‖_F² / ‖W_base H_X‖_F²` | X 層出力が何割変わるか（層・ドメイン比較用） |
| 向きのみ([0,1]) | `‖ΔW_i S_X‖_F² / ‖ΔW_i‖_F²` | 更新エネルギーが X の上位部分空間に乗る割合（大きさ統制・GPM/InfLoRA流） |
| 交絡統制用 | `‖ΔW_i‖_F²` | 更新量そのもの（「量」か「向き」かの分離に使用） |

## 座標系の統一（妥当性レビュー反映）
**重要部分空間は「保存したい出力を出すモデル」上で計算**し、更新はその起点からの差分にする:
- COCO 忘却（単独FT, exp_005）: `C_COCO` は **base** 上、`ΔW_i = W_i − W_base`。
- aerial 忘却（逐次FT, exp_006）: `C_aerial` は **aerial ckpt** 上、更新 `= W_(aerial→D2) − W_aerial`。

## end-to-end の忘却（実体・別測）
層別干渉は一次近似のため、**忘却そのもの**は最終出力で直接測る:
- base(or aerial) と忘却モデルに X を流し、**領域–テキスト対照ロジット／検出ボックス・スコアのドリフト**を比較。
- 層別干渉（どこで注入されるか）と end-to-end ドリフト（実体）を併記。

## 対象層
学習される共有線形層のみ（backbone・言語は凍結＝対象外）:
decoder（self/cross-attn(画像)/cross-attn(text)/FFN の Linear, 6層）, encoder（self-attn/FFN/fusion）,
neck（ChannelMapper 1×1 conv＝チャネル線形）, bbox_head（reg_branches/cls 対照分岐）。
初期は全対象、分析A の局在化結果で重点層を絞る。

## 分析A: 忘却の局在化（→ 不実施。分析C の層別干渉で兼ねる）
当初の「モジュール復元実験」は、**backbone を凍結している現設定では復元できる部品が neck/encoder/decoder/head に
限られ、backbone が原因かを検証できない**（一度も書き換わっていない）。完全な局在化には backbone 学習ありの
追加 run が要るが、本手法は backbone 凍結方針のため**過剰**。
→ **分析A は実施しない**。局在化は **分析C が層ごとに出す干渉量（trace ベース）= モジュール別の局在化**で代替する
（どの層/部品の更新が最も干渉するかが C から直接分かる）。
※「分類 vs 局在の忘却」は将来の手法考察で必要なら別途検討（現フェーズでは見送り）。

## 分析B: 適応の低ランク性（→ rank r）
各単独FTの `ΔW_i^ℓ` を SVD し、特異値スペクトル・実効ランク・上位 r 累積エネルギー比を層ごとに算出
（単一値でなくスペクトルで報告）。→ rank をデータdrivenに決定（[[../../papers/forgetting-analysis/IntrinsicDimensionality_summary]]）。

## 分析C: 部分空間干渉（中核）
### 手順
1. **C_X / S_X**: 該当モデル（上記 座標系）に X のプローブを流し、層 ℓ の入力活性化のグラム行列
   `C_X^ℓ = Σ h hᵀ` を逐次累積→固有分解。上位（エネルギー95% or 固定k）で S_X^ℓ。（活性化は保存せずグラムのみ＝安価）
2. **ΔW_i^ℓ**: 起点モデルからの差分。
3. 上記「干渉指標」3種を層ごとに算出（絶対・相対・向きのみ）＋ `‖ΔW_i‖`。
4. 集約: 層→層グループ（重み付き平均）→ ドメイン×ドメイン・ドメイン×COCO の干渉行列（heatmap）。

## 分析D: 干渉と忘却の相関（中核）
実測忘却（exp_005/006）と分析C の干渉を相関:
1. **COCO 忘却（6点）**: x=干渉(i→COCO), y=`F_COCO(i)=0.504−COCO_after(i)`。
2. **過去ドメイン忘却（5点）**: x=干渉(D2→aerial), y=`F_aerial(D2)=0.468−aerial_after(D2)`。
- **Spearman 順位相関を主**（少点数に頑健）、Pearson 従。層別の一貫性で補強。
- **交絡統制**: `‖ΔW_i‖` 単独の相関も出し、向き成分（向きのみ指標）との**偏相関**で「量」と「向き」を分離。
- **限定**: 点数が 6・5 と少なく**相関＝示唆**（因果でない）。断定せず、因果は分析E と手法(C3)に委ねる。

## 分析E: 因果ミニ検証（直交除去で忘却が減るか・学習不要）
干渉成分を除いたら忘却が実際に減るかを直接確認（提案手法の概念実証も兼ねる）:
1. ドメイン i の更新を X の重要部分空間の**直交補へ射影**: `ΔW_i^⊥ = ΔW_i (I − S_X S_Xᵀ)`（入力側射影）。
2. `W' = W_base + ΔW_i^⊥`（対象層に適用、複数層同時）。
3. 評価: (a) X（COCO/aerial）が回復するか、(b) ドメイン i 性能が大きく落ちないか。
- 成立すれば「**直交化が忘却を減らす**」を相関を超えて因果的に示せる。
- 注意: 層ごと射影＝一次近似のため、複数層に適用し **end-to-end で評価**して妥当性を担保。

## 想定される懸念点（妥当性の限界を明示）
1. **一次・1層近似**: 層別干渉は入力固定の一次量で、多層非線形合成の end-to-end 忘却とは別。
   → end-to-end ドリフト（実体）と分析E（複数層・end-to-end評価）で補う。
2. **座標系**: 重要部分空間は保存対象モデル上で計算（COCO=base, aerial=aerial ckpt）。ΔW は同一起点・同一 shape で比較。
3. **入力側統一**: S_X（活性化）と射影 (I−S_X S_Xᵀ) はともに入力空間 d_in。
4. **少点数(6,5)**: 相関は示唆。Spearman＋層別一貫性＋偏相関で補強、断定しない。
5. **二段検出器知見の転用は仮説**（A-2）。num_classes 依存層は比較・復元対象外。
6. **attn の Linear 取り出し**（in_proj 連結等）に注意。FFN/out_proj から着手。neck は 1×1 のみ線形扱い。

## 成功基準
- 分析A〜E が完走し、(C) 干渉行列・(D) 干渉↔忘却の相関・(E) 直交除去による回復が得られること。
- **「忘却は共有検出経路の部分空間干渉で説明でき（C/D）、干渉成分の直交除去で軽減できる（E）」**を示し、
  手法設計（LoRA 挿入箇所・rank・COCO を task-0 とする直交対象）を根拠づける結論を notes に示すこと。
- 結果を手法フェーズ（C3）の設計に直接引き継ぐこと。
