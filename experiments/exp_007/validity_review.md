# exp_007 機序分析の妥当性レビュー

作成日: 2026-06-21。exp_007 の分析(A 局在化 / B 低ランク性 / C 部分空間干渉 / D 干渉↔忘却相関)が
「手法(C3)の動機付け」として妥当かを批判的に検討する。関連: [[design]]

## 総合結論
- **手法駆動の動機付け(supporting)としては妥当**。InfLoRA/GPM と同じ理論枠組みに乗っており、
  既存資産で安価に実施できる。
- ただし **そのままでは方法論的な穴が複数**あり、修正が必要:
  1. 部分空間の**座標系の不一致**（base vs 起点モデル）。
  2. 忘却が「**更新の大きさ ‖ΔW‖**」か「**更新の方向(干渉)**」かの**交絡**。
  3. 分析C は**1層・線形近似**の代理量で、end-to-end の忘却を直接測っていない。
  4. 分析D は **6点・5点**と統計的検出力が低く、相関に留まる（因果でない）。
- → **分析C/D は「相関による示唆」までしか主張できない**。手法の正当化には
  **因果的ミニ検証（直交射影で忘却が実際に減るか）を追加**するのが必須に近い（下記 修正5）。
- 主貢献は手法(性能)なので、機序分析が決定的証明でなくても研究は成立する。
  ただし「妥当でない主張」をしないよう、結論の言い方を相関/示唆に限定する。

---

## 各分析の妥当性

### A. 局在化（モジュール復元）— 概ね妥当・要三角測量
- **妥当な点**: 「1モジュールを忘却前に戻して回復量を見る」は直接的な因果操作。LoRA 挿入箇所の根拠になる。
- **脅威**:
  - **非分離性**: 忘却が複数モジュールに分散し相互作用する場合、単一復元では回復しきれず**過小評価**しうる。
  - **num_classes 依存層は復元不可**（D1=22, D2=59 等で shape 不一致）。eval 非関与の label_embedding は除外で
    妥当だが、共有経路に他の shape 不一致がないか**事前確認**が必要。
- **修正**: 「**Xだけ復元**」と「**X以外を全部復元**」の両方を測って三角測量。層別 ‖ΔW‖（分析B）とも突き合わせる。

### A-2. 分類 vs 局在の切り分け — 妥当だが転用に注意
- **脅威**: 「分類は忘れ局在は残る」は**二段検出器(Faster R-CNN)**の知見で、Grounding DINO（クエリ＋
  テキスト対照、RoI分類器なし）にそのまま転用できない。固定提案による切り分けも機構が異なる。
- **修正**: クエリ系に合わせて再定義する — (a) 局在＝スコア無視で GT との IoU が出るか（localization recall）、
  (b) 分類＝正しいクラス/スコアが付くか（対照整合）。**「転用できるかの仮説検証」**として位置づける（断定しない）。

### B. 低ランク性（ΔW の SVD）— 妥当
- **妥当な点**: ΔW のスペクトル/実効ランクは標準的で直接的。Intrinsic Dimensionality 文献と整合。
  対象は凍結下で実際に学習した共有層＝LoRA を入れる層そのものなので適切。
- **脅威**: 実効ランクはエネルギー閾値依存 → **単一数値でなくスペクトルを報告**。
- 妥当性: 高い。rank 選択の根拠として問題なし。

### C. 部分空間干渉 — 代理量として妥当だが限界明示が必須
- **理論的妥当性**: 「更新が旧入力部分空間に乗る分だけ旧出力が変わる」は GPM/InfLoRA の根拠と同一。
  指標 `overlap(U_i,S_X)=‖U_iᵀS_X‖²/min(k)` は主角度ベースで標準的。
- **脅威（重要）**:
  1. **1層・線形の局所近似**: 深い非線形網では層ℓの更新が層ℓ+1 の入力を変えるため、**層ごとの直交性は
     end-to-end の出力保存を保証しない**。干渉指標は first-order の代理。InfLoRA/GPM も同じ近似に依存するが明記すべき。
  2. **入力活性化 ≈ 勾配空間の代理**: 勾配 ∂L/∂W=(∂L/∂e)hᵀ は入力 h（行空間）と出力勾配 ∂L/∂e（列空間）の積。
     S_X は h 側のみ捕捉。**出力勾配側の干渉は見ていない**（GPM と同じ簡略化）。
  3. **U_i は ΔW の入力側(右特異ベクトル)を使う**こと（S_X が入力空間 dI のため）。左右を取り違えると無意味。
  4. **座標系**: S_X は「保存したい出力を出すモデル」上で計算すべき（修正1参照）。
- **妥当性**: 代理量としては妥当。ただし上記1〜4を明示し、**「end-to-end の忘却そのものではなく、忘却を生む
  局所的干渉の指標」**と限定して使う。

### D. 干渉↔忘却の相関 — 示唆に留まる（最も弱い）
- **脅威（重要）**:
  1. **点数が少ない**（COCO 6点・aerial 5点）。1〜2点の外れ値で相関が左右され、Pearson は不安定。
  2. **大きさとの交絡**: 忘却が `overlap`（方向）でなく `‖ΔW‖`（更新量）で説明できる可能性。
     overlap を [0,1] 正規化しても、両者が相関するなら**偏相関**で分離が必要。
  3. **相関 ≠ 介入効果**: overlap が忘却と相関しても、「直交化を強制すれば忘却が減る」ことの証明にはならない。
- **修正**: **Spearman 順位相関**（少点数に頑健）で「干渉で忘却を順位づけできるか」を主張。
  `‖ΔW‖` 単独の相関も併記し**偏相関**で方向成分の寄与を分離。**断定せず「示唆」と表現**。

## 横断的な妥当性の脅威と修正（actionable）
1. **座標系の統一**: 保存対象の出力を出すモデル上で重要部分空間を計算する。
   - COCO 忘却（単独FT, exp_005）→ S_COCO は **base** 上、更新 ΔW_i は base 基準。整合。
   - aerial 忘却（exp_006, aerial→D2）→ S_aerial は **aerial ckpt** 上で計算、更新は **W_(aerial→D2)−W_aerial**。
     （design の「全て base で統一」は aerial ケースで不整合 → **要修正**）。
2. **入力側部分空間に統一**: S_X（活性化 h）と U_i（ΔW の右特異ベクトル）はともに入力空間 dI で比較。
3. **大きさ交絡の制御**: `‖ΔW_i‖` を別途測り、忘却との相関を確認。overlap との**偏相関**を報告。
4. **少点数への対処**: Spearman 主、Pearson 従。層別の一貫性（多くの層で同傾向か）で補強。
5. **因果ミニ検証（最重要・妥当性を格上げ）**: ドメイン i の更新 ΔW_i を **S_COCO の直交補へ射影**して
   base に適用し、(a) COCO が回復し (b) ドメイン i 性能が大きく落ちないかを評価（**学習不要**）。
   - これが成立すれば「**直交化が忘却を減らす**」を**因果的に**示せ、C/D の相関を超えた根拠になる。
   - 提案手法(InfLoRA型)の先行概念実証も兼ねる。design の任意「分析F」を**必須級に格上げ**推奨。
6. **非分離性**: 局在化は単一復元＋leave-one-out 復元の双方で三角測量。

---

## 妥当性の限界（正直な明示）
- 分析C/D は **InfLoRA/GPM と同じ線形・局所近似**に依存し、end-to-end の忘却の直接測定ではない。
- 統計的検出力は低く（6・5点）、**因果でなく相関/示唆**。
- 二段検出器の機序知見の Grounding DINO への転用は**仮説**であり、本分析で検証する対象。
- → これらを踏まえ、結論は「忘却は部分空間干渉と**整合的で**、直交化が**有望**」という**動機付けの強さ**に留め、
  決定的証明は手法(C3)の性能比較に委ねる。

## 結論：実施可否
- **実施は妥当**。ただし design.md を以下で更新してから実施する:
  - 座標系を保存対象モデル基準に修正（修正1）、入力側統一（修正2）。
  - ‖ΔW‖ 交絡の制御・Spearman（修正3,4）。
  - **因果ミニ検証（直交射影で忘却回復）を必須分析に格上げ**（修正5）。
  - 局在化の三角測量（修正6）。
- これにより「相関で示唆 → 直交射影で因果を補強 → 手法で決着」という妥当な論理になる。
