## 0. 位置付け

exp_028 が条件A で蒸留対象を **L2ノルム**で切り分けるのに対し、本実験は**同じ切り分けをコサイン類似度で行う**。
L2 とコサインで何が変わるかは exp_028 §4.3.2 に記載のとおり、**固定するものが違う**。

| 形式 | 制約されるもの | 自由に動けるもの |
|---|---|---|
| L2（exp_028/029） | 各 $(l, c, h, w)$ の値そのもの | なし |
| **コサイン（exp_030/031）** | 各位置の 256 次元ベクトルの**向き** | ベクトルの**ノルム** |

コサインのほうが制約が緩いため、忘却抑制は弱いが適応は保たれる、という結果になり得る。逆に、
特徴の大きさが変わること自体が忘却の主因であれば、コサインでは抑えられない。**この差を見るのが本実験の狙いである。**

（float64 の参照実装との差 2.2e-16）。

## 3. コサイン形式で期待される値域（実行前に実測する）

L2 では**特徴の絶対的な大きさ**に損失が支配され、λ = 1.0 のとき蒸留対象間で実効強度が
最大4桁違っていた（exp_028 §4.5 の実測。蒸留B は検出損失を上回り、蒸留D は 0.3%）。

$1 - \cos$ は **$[0, 2]$ に収まり特徴の大きさに依存しない**ため、この不均衡は原理的に生じない。

**実測（2026-07-29、underwater、5バッチ平均、λ=1.0）**:

| | `kd_img` | `kd_txt` | `kd_fus` | `loss_kd`(E) |
|---|---:|---:|---:|---:|
| L2 eval 下限（$\theta^S=\theta^T$） | 0.000000 | 0.000000 | 0.000000 | — |
| L2 開始時（train） | 0.149397 | 3.095640 | 0.000931 | 1.081989 |
| L2 ドリフト後 | 0.277651 | 6.973532 | 0.014738 | 2.421973 |
| **cos** eval 下限 | 0.000000 | 0.000000 | 0.000000 | — |
| **cos** 開始時（train） | 0.066202 | 0.006298 | 0.012432 | 0.028311 |
| **cos** ドリフト後 | 0.082650 | 0.021289 | 0.088958 | 0.064299 |

**対象間のばらつきは L2 の 473倍からコサインの 4.2倍に縮む**（ドリフト後の最大/最小）。
狙いどおり、**exp_030/031 のほうが「どこに蒸留をかけると効くか」の比較として素直に読める**。

一方で**全体の強さは弱くなる**。$\lambda = 1.0$ のとき蒸留E の `loss_kd` は L2 で 2.42、
コサインで 0.064（38倍の差）であり、検出損失（同条件で約 5.2）に対する比は L2 47% に対し
**コサインは 1.2%** にとどまる。§7 の限界を参照。

$\lambda = 1.0$ は exp_028/029 と共通（2026-07-27 決定）。

## 4. 対照・評価・判定基準

exp_028 と同一。

- **対照**: exp_027-1（条件A・リプレイのみ）。t=1 適応 0.337 / ZCOCO 0.411、t=2 適応 0.475 /
  過去uw 0.229 / ZCOCO 0.382、t=3 適応 0.726 / 過去uw 0.230 / 過去em 0.428 / ZCOCO 0.368。
- **評価**: 各ドメイン後に現在＋全過去＋ZCOCO。
- **判定基準**: 適応と忘却のトレードオフを解決しているものを残す。判定はユーザーが行う。
- **差を読む基準**: 同一環境の再実行で 0.001〜0.007、環境間で最大 0.012。

加えて本実験では、**同じ蒸留対象の L2 版（exp_028）との対比**が主要な読みどころになる。

## 7. この実験で言えないこと（限界）

exp_028 §9 と同じ限界に加えて、

- コサインは特徴の**ノルム**を制約しない。忘却がノルムの変化に起因していた場合、それを抑えられない
  のは設計上の帰結であり、「コサインが劣る」という一般的な結論には直ちにならない。
- **$\lambda=1.0$ のときコサインの蒸留は検出損失の 1.2% にとどまる**（§3 の実測）。結果が
  「コサインは効かなかった」となった場合、**形式の性質なのか強度不足なのかを exp_030 単体では
  分離できない**。分離するには exp_028 §4.5 の校正で強度を揃えた条件が要る。
- L2 とコサインの比較は $\lambda = 1.0$ 共通という条件下のものである。強度を揃えた比較ではない
  （exp_028 §4.5 の校正手順を使えば揃えられるが、今回は行わない）。
