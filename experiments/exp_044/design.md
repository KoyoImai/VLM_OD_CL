## 0. 位置付け

note07 の蒸留（exp_028 系）は「学生の特徴を**直接**教師に近づけ、対象は**バッファ由来
サンプルに限定**」だった。本実験は蒸留Eを次の 2 点で変更した**蒸留E+**を、既存系列と
同一の学習枠で**前半 3 ドメイン**（2026-08-16 変更。当初は 6 ドメイン通し）で走らせ、
note07 の方法（exp_035 = λ=10 蒸留E の前半 3 ドメイン）と比較する。

1. **projector 蒸留**: 学生の特徴を projector に通し、projector の出力を教師の特徴に
   近づける（教師側はそのまま）。
2. **蒸留対象の全データ化**: バッファ限定をやめ、ミニバッチの全サンプルに蒸留を掛ける。

### 2.2 蒸留E+ の仕様（2026-08-16 の議論で確定）

| 項目 | 決定 |
|---|---|
| 蒸留点（4点） | 従来の蒸留E と同じタップ位置を 4 つに分けたもの: ①neck 後のマルチスケール画像特徴（256ch）②text_feat_map 後のテキスト特徴（256d）③融合後画像側 memory（256d）④融合後テキスト側 memory_text（256d） |
| projector | **4 点それぞれに独立**な同型の点ごと 2 層 MLP `Linear(256→256) → GELU → Linear(256→256)`（画像側は各空間位置に適用＝1×1 conv として実装、テキスト側はトークンごと）。**標準初期化・残差なし**。パラメータ約 0.53M（4 × 131,584） |
| projector の学習 | 学生と同じ optimizer・学習率で同時に学習。**タスク間は引き継ぐ**（state_dict に含め load_from で持ち越し。評価は plain モデルで行い projector は不使用） |
| 蒸留対象データ | **ミニバッチ全サンプル**（バッファ限定なし） |
| 損失 | 従来と同じ集計: L2、3 項（img, txt, fus）の平均、fus は画像側・テキスト側の 0.5·(l_img+l_txt)。学生特徴のみ projector を通す点だけが差 |
| λ / 適用期間 | 10 / 全 epoch |
| 教師 | θ_{t-1}（t=1 は θ0）。ドライバが `model.teacher_ckpt` で渡す |

恒等初期化について: 非線形 MLP（残差なし）では「初期化直後に出力＝入力」は原理的に
不可能である（GELU を線形層で打ち消せない）ことを確認したうえで、標準初期化の素の
2 層 MLP を採用した（2026-08-16 決定）。学習初期の蒸留損失はランダムな projector の
ぶん大きく出る。

## 6. リスク・懸念

- **学習初期の蒸留損失が大きい**（projector が標準初期化のため）。λ=10 でも grad clip
  0.1 が効くので発散はしにくいが、序盤の loss_kd の推移をログで確認する。
- **projector 付き蒸留は「教師に一致させる」制約を弱める**（projector が差を吸収できる）。
  これは手法の意図（学生の表現自由度を残しつつ知識を保つ）そのものであり、
  結果がどちらに出ても note07 との対照として読む。
- projector キーが ckpt に含まれるため、この ckpt を他実験の初期値に流用する場合は
  unexpected keys が出る（無害だが記録しておく）。
