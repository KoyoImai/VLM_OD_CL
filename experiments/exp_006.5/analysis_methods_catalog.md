# 機序分析(C2) 手法カタログ — 既存研究由来の分析方法の統合

作成日: 2026-06-21。これまでの調査（[[related_work_survey]] 直球4領域 ＋ [[related_work_survey_extended]] 広域＋領域8精査）から、
本プロジェクト（事前学習VLM検出器 MM-Grounding DINO のドメイン増加CL・ZCOCO保持）で**使える分析方法**を統合した参照カタログ。

目的: C2機序分析の design.md を書く際の道具箱。各手法を「何を測る／出典／MM-GDINOでの計算（必要ckpt）／支持する主張・設計判断／コスト／caveat」で記す。
方針: **大半は既存チェックポイント(exp_005 単独FT×6, exp_006 逐次)＋軽い順/逆伝播で実施でき、再学習はほぼ不要**。

---

## 0. 分析の狙い（InfLoRAの3前提 × 本研究の独自軸）
提案手法(InfLoRA型 LoRA＋COCOをtask-0として直交保護)の妥当性を、以下を実証することで支える。

| 前提/軸 | 示すこと | 主担当の分析ファミリ |
|---|---|---|
| ① 適応は低ランク | fine-tune の ΔW が低ランク | F1（重み空間） |
| ② 忘却は共有パラメータの干渉 | ドメイン間で更新/勾配/表現の部分空間が重なる | F2（勾配・部分空間）, F3（表現） |
| ③ 直交化で干渉が消える | 直交射影で忘却が減る | F5（局在化・因果） |
| 独自軸: ZCOCO保持 | COCO部分空間も干渉対象＝保護が要る | F6（保持指標）＋ F2/F3 にCOCOを含める |
| 補完機構の前提 | 重み平均/補間が効く損失地形か | F4（損失地形） |

## 推奨実施順（論理の一直線化）
1. **F1 ΔW低ランク**（rank r 決定・①） → 2. **F2 部分空間/勾配の重なり**（干渉の実在・②） →
3. **F3 表現プローブ＋F5 巻き戻し**（崩壊かヘッドかを切り分け・挿入箇所決定） →
4. **F2/F4 ↔ F0 の相関**（干渉量・地形が実測忘却を説明するか） → 5. **F6**（COCO保護の動機・独自軸） →
6. **F5 直交射影mini検証**（③ 直交化で実際に減る・因果の決定打）。

→ **中核は F2（干渉の定量化）と F5（局在化・因果）**。F2 に COCO を task-0 として含める(F6)ことで独自拡張まで一直線に動機づく。

## コスト別の優先（予算配分）
- **低コスト・即実施可**: F1, F5(巻き戻し/task否定), F4(補間バリア), F6(ZCOCO追跡)。既存ckpt＋評価のみ。
- **中コスト**: F2(活性化/勾配/Fisher), F3(プローブ/CKA/tunnel), F4(sharpness)。順/逆伝播が要る。
- **高コスト・任意**: F2 NTK重なり（近似で代替可）。

## 全体 caveat
- F2/F3/F4 の多くは**分類での知見**で、検出Transformer・対照/クエリヘッド・言語枝への転移は**我々が検証すべき仮説**（＝貢献余地）。
- NTK系・平坦性は理想化/近似に依存。アラインメントは「忘却の予測子」であり不変則ではない（非単調報告あり）。
- 線形プローブ・CKA は検出向けに**領域(region)単位**へ適応が必要。
