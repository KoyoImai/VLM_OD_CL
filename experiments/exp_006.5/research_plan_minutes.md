## 2. 議論：機序分析(C2)をどう設計するか

### 2.1 基本方針
機序分析は単なる現象記述ではなく、**「LoRA + 干渉除去(InfLoRA型)がなぜ効くのか、その前提が
本設定で成り立つか」を実証**するものにする。InfLoRA の3前提を1つずつ検証する構成とする。

| InfLoRA の前提 | 機序分析で示すこと | 手法設計への直結 |
|---|---|---|
| ① 適応は低ランク | fine-tune の ΔW が低ランク | LoRA で十分・rank r 決定 |
| ② 忘却は共有パラメータの干渉 | ドメイン間で更新/勾配の部分空間が重なる | 干渉除去（直交化）の動機 |
| ③ 直交化で干渉が消える | 直交射影で忘却が減る（mini検証） | 手法有効性の先行根拠 |

### 2.2 具体的な分析項目（5+1）
**いずれも既存チェックポイント(exp_005/006)＋軽い順伝播で実施可能、再学習はほぼ不要。**

- **分析A: 忘却の局在化** — 忘却モデルの1モジュールだけ重みを忘却前に戻し再評価。忘却源モジュール特定。
  → LoRA 挿入箇所を決定。
- **分析B: 適応の低ランク性** — 各単独FTの ΔW を SVD、特異値スペクトル・実効ランク・上位r エネルギー比。
  → rank r をデータdrivenに決定。
- **分析C: ドメイン間の部分空間干渉（機序の核）** — 各ドメインの更新部分空間（ΔW上位r）または
  入力活性化部分空間（GPM流）の重なりを主角度/射影エネルギーで定量化。干渉の実在を示す。
  → 直交化設計の直接的根拠。
- **分析D: 干渉量と忘却量の相関（機序の核）** — 分析Cの重なりと実測忘却（exp_005のCOCO×6、
  exp_006のD1×5）を相関。「忘却 ∝ 部分空間の重なり」を示し、距離依存を干渉量として機序化。
- **分析E: COCO 保護の根拠** — 各ドメイン更新部分空間と事前学習(COCO)部分空間の重なりを測定。
  ゼロショット喪失を干渉で説明 → 「COCO を task-0 として直交対象に含める」独自拡張の動機。
- **（任意）分析F: 直交射影 mini 検証** — ドメインB更新をA/COCO の直交補へ射影適用し忘却が減るか。
  フル手法前の概念実証（因果の決定打）。

### 2.3 推奨構成（論理の一直線化）
LoRAで十分(B) → 忘却は干渉(C) → 干渉が忘却を説明(D) → COCOも保護対象(E) → 直交化で実際に減る(F)。
優先順位: ①A+B（手法の前提）→ ②C+D（機序の核・動機）→ ③E（独自貢献の動機）→ ④F（因果の決定打）。

## 6. exp_007（機序分析）結果と手法方針の確定（2026-06-21）
### exp_007 の結論
- 忘却の正体 = 新ドメイン学習で**共有検出重みが COCO/過去ドメインの重要部分空間方向に動く**こと
  （直交除去すると COCO が回復＝**因果的に確認**: documents 0.275→0.48, underwater 0.414→0.49）。
- **だが適応も同じ部分空間に依存**（直交除去すると自ドメイン崩壊: documents 0.478→0.089, underwater 0.316→0.168）。
  ＝**適応と忘却が同一部分空間を奪い合う**（documents/underwater 両極で普遍。遠いほど依存大）。
- 干渉量と忘却量の相関(C/D)は出ず（活性化部分空間の重なりは忘却の良い予測子でない）。機序は因果(E)で実証。
- 適応は中程度の低ランク（上位16で56〜89%）。

### 手法方針の確定（ユーザ決定）
- **LoRA は分離・保持しない。各タスク学習後にベース重みへマージする**（InfLoRA/再パラメータ化方式、**パラメータ数一定**）。
  → 当初案の「ドメイン別 LoRA 分離（モジュール式/DitHub 型）」は**不採用**。
- **中心課題**: マージ＝共有重み更新なので exp_007 の奪い合いが直撃。
  **素朴な「COCO 部分空間と直交化してマージ」は不成立**（適応が壊れる）。
  → 手法の核心は「**マージしても奪い合いを最小化する更新の作り方**」
  （過去ドメインのみ直交化＋COCO は ZiL 的 soft 保護、rank/スケール抑制、トレードオフ点の探索）。

### 実験番号の整合

  exp_009（joint上限）/exp_010（順序）**、手法は exp_011 以降に繰り下げ（[[../research_plan]] 参照）。
