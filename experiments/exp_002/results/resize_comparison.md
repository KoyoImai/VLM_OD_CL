## 主要な観察
1. **S4（正方形固定）は RF100 全ドメインで S1 と完全一致**。RF100 は元から 640×640 正方形なので
   keep_ratio の有無は無関係。差が出るのは非正方形の **COCO のみ**（0.499→0.478 と低下＝歪みは有害）。
2. **S3（短辺1333）は全対象で大幅劣化**。特に COCO は 0.504→0.021 と崩壊。学習分布（短辺〜800）から
   逸脱した過度なアップスケールは精度を破壊する。aerial/videogames は評価完了後にプロセス終了時
   クラッシュ（ChildFailedError）したが、mAP は算出済みで値は有効。→ 高解像度は採用しない。
3. **640 / 800 / 1024 は概ね誤差範囲**（RF100 ドメインで ±0.002〜0.003）。
   - S2(1024) は COCO(0.507) / aerial(0.037, mAP_s=0.059) / electromagnetic(0.025) で僅かに最良。
   - 一方 underwater(0.049) / documents(0.005) では S1/baseline より僅かに劣る。一貫した勝者ではない。
   - S1(640) は baseline(800) とほぼ同値で、**アップスケールなし＝最速**。
