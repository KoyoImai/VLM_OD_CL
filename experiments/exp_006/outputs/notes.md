# exp_006 メモ：2ドメイン逐次学習（D1=aerial → D2）

## 結論（目的達成）
aerial(D1) を学習済みのモデルから各 D2 を継続学習した結果、**D2 学習後に aerial(D1) の検出性能が
全ケースで低下**した（0.468 → 0.099〜0.241）。exp_005 までの「COCO（事前学習知識）の忘却」に加え、
**「過去に学習したドメインの忘却」も起きる**ことを実証した。

| D2 | aerial(D1) | D1忘却 | D2適応 | COCO |
|---|---:|---:|---:|---:|
| (基準: aerial単独FT後) | 0.468 | — | — | 0.318 |
| videogames | 0.241 | −48.5% | 0.698 | 0.214 |
| electromagnetic | 0.147 | −68.6% | 0.466 | 0.216 |
| microscopic | 0.127 | −72.9% | 0.503 | 0.163 |
| underwater | 0.113 | −75.9% | 0.313 | 0.355↑ |
| documents | 0.099 | −78.8% | 0.481 | 0.128 |

## 観察と解釈
1. **過去ドメイン忘却は普遍的かつ深刻**: D1(aerial) は最良でも −48.5%、最悪 −78.8%。
   たった1つ後続ドメインを学習しただけで D1 性能が半分〜1/5 になる。継続学習の中核課題を実証。
2. **新ドメインの学習自体は健全**: D2 適応は単独FT（事前学習起点）とほぼ同値（差±0.02）。
   忘却は「学習能力の問題」ではなく「共有重みの上書き」によるもの。
3. **COCO は概ねさらに低下するが、underwater は例外的に回復**（0.318→0.355）。
   underwater は COCO に近く（fish/penguin 等）、D2学習が共有検出経路を COCO 寄りに引き戻す。
   → 「忘却量はドメイン間距離に依存」という exp_005 の仮説を、逐次学習でも支持。
4. **D2 が COCO から遠いほど D1・COCO の忘却が大きい**: documents（最遠）が D1忘却最大(−78.8%)・
   COCO最低(0.128)。近い underwater は COCO 回復・D1忘却もやや小さめ。
5. backbone・言語凍結下でも忘却は強い → 忘却源は共有検出デコーダ/ヘッド（exp_004 仮説）を再確認。

## 妥当性
- 全5本で同一設定（凍結・lr1e-4・実効64・20ep・seed=0）、D1 起点も同一 aerial ckpt。比較は公平。
- 評価は (800,1333) 統一。D2 適応は学習中 val と test 一致。OOM なく全完走。
- aerial 起点パラメータの使用は実験前に検証済み（凍結部一致・学習部相違）。

## 次の問い・改善案
1. **6ドメイン逐次学習（本丸・次段）**: 2ドメインで忘却を確認できたので、6ドメイン全逐次で
   (a) 各ドメインの段階的忘却、(b) COCO累積忘却、(c) ドメイン順序の影響、(d) 平均mAP/forgetting/hAP
   （ZiRa 指標）を測る。
2. **ドメイン順序の影響**: underwater のように COCO/近傍ドメインを後段に置くと回復が起きるなら、
   順序が最終性能に影響するはず。順序 ablation を設計。
3. **忘却抑制手法（ZiRa 型）導入**: 本実験の標準逐次FT（D1 −48〜−79%）に対し、
   アダプタ＋ZiL でどれだけ D1/COCO を保持できるか比較（対策の本命）。
4. **忘却量とドメイン距離の定量化**: CLIP特徴やクラス語彙重なりで距離を測り、D1忘却・COCO忘却と相関検証。
