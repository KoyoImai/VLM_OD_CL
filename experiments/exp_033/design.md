## 0. 位置付け

exp_028（λ = 1.0）の結果では、蒸留の有無による差が**ばらつきの範囲（0.001〜0.007）をほとんど
出なかった**。本実験は**同じ枠組みのまま係数だけを 2.0 / 3.0 / 5.0 に上げ**、強度を上げれば
効果が現れるのかを確かめる。

exp_032（比率追従）との違いは次のとおり。

| | exp_028 | **exp_033** | exp_032 |
|---|---|---|---|
| 重みの決め方 | 固定係数 | **固定係数** | 比率追従 |
| 設定値 | λ = 1.0 | **λ = 2.0 / 3.0 / 5.0** | ρ = 0.1 / 0.5 / 1.0 |
| 対象間の実効強度 | 揃わない（473倍差） | **揃わない（同じ 473倍差）** | 揃う |

**exp_033 は「強度を上げる」実験であり、「対象間で揃える」実験ではない。**両者を分けて扱うことで、
exp_032 との比較から「揃えることに意味があるか」も読める。

## 3. 各条件の実効強度（実測からの外挿）

λ は損失に線形に効くので、exp_028 で測った値（underwater・5バッチ平均）から正確に外挿できる。

### ドリフト後（学習後半に相当。検出損失 5.17 に対する割合）

| λ | A（画像） | B（テキスト） | D（融合後） | E（3項平均） |
|---:|---:|---:|---:|---:|
| 1.0（exp_028） | 5.4% | 134.8% | 0.3% | 46.8% |
| **2.0** | 10.8% | 269.6% | 0.6% | 93.6% |
| **3.0** | 16.1% | 404.4% | 0.9% | 140.4% |
| **5.0** | 26.9% | **674.1%** | **1.4%** | 234.0% |

### 学習開始時（$\theta^S = \theta^T$。中身はほぼ dropout ノイズ。検出損失 17.97 に対する割合）

| λ | A | B | D | E |
|---:|---:|---:|---:|---:|
| 1.0 | 0.8% | 17.3% | 0.0% | 6.0% |
| **5.0** | 4.1% | **86.3%** | 0.0% | 30.1% |

### この表から読める設計上の注意（3点）

1. **蒸留D は λ = 5.0 でも検出損失の 1.4% にしかならない。** exp_028 の 0.3% から上がるが、
   依然として無視できる水準である。**この掃引で蒸留D に有意な変化が出る見込みは薄い。**
   蒸留D の強度を上げたいなら比率追従（exp_032）か、対象ごとの係数指定が必要になる。
2. **蒸留B は λ = 5.0 で検出損失の 6.7 倍になる。** 適応が大きく損なわれる可能性がある。
   これは掃引の目的（強くしたときに何が起きるか）に沿った条件ではあるが、**学習が破綻して
   評価不能になる可能性**も含む。破綻した場合も「強すぎる側の端点が分かった」という情報にはなる。
3. **学習開始時、蒸留B（λ=5.0）は検出損失の 86% がノイズ由来になる。** $\theta^S=\theta^T$ の
   区間では $\mathcal{L}_{\mathrm{KD}}$ の中身が dropout と drop path の揺らぎだけであるため。
   ドリフトが溜まるまでの数エポックは、ノイズを抑える方向に勾配が流れる。

## 4. 対照・評価・判定基準

- **対照1（蒸留なし）**: exp_027-1。t=3 で 適応 0.726 / 過去uw 0.230 / 過去em 0.428 / ZCOCO 0.368。
- **対照2（λ = 1.0）**: exp_028 の同じ蒸留対象。**掃引の起点。**
- **評価**: 各ドメイン後に現在＋全過去＋ZCOCO。プロトコルは exp_002.5 準拠。
- **判定基準**: 適応と忘却のトレードオフを解決しているものを残す。判定はユーザーが行う。
- **差を読む基準**: 同一環境の再実行で 0.001〜0.007、環境間で最大 0.012。

λ を4点（1.0 を含む）持つことで、**対象ごとに強度と性能のトレードオフ曲線が描ける**のが本実験の
主要な出力になる。

   係数に依存しないため再実施しない。

## 7. この実験で言えないこと（限界）

- **蒸留D については実質的に何も分からない**（§3-1）。λ を5倍にしても 1.4% にしかならない。
- λ は全対象で共通なので、**対象間の実効強度の差（473倍）は掃引しても解消されない**。
  「どこに蒸留をかけると効くか」は依然として強度の差を含んだ比較になる。
- 各条件1試行。0.01 前後の差はばらつきと区別できない。
- λ = 5.0 で学習が破綻した場合、それが「強すぎたから」なのか「学習初期のノイズ増幅（§3-3）が
  原因」なのかは、本実験だけでは分離できない。
