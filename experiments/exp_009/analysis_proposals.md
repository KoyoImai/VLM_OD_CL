# exp_009 分析提案カタログ — MM-Grounding DINO の継続学習における忘却分析

作成日: 2026-06-26。Step2(既存研究の再調査)＋Step3(提案)の成果物。
**各提案は「文献的根拠／MM-GDINOへの具体的落とし込み／実行可能性／VLM固有性／結果が手法を分岐させるか／自分で潰したcaveat」**で記す。
土台: アーキ理解 [[../../setup_and_code_analysis/code_analysis/mmgrounding_dino_architecture]]。θ0=事前学習, θ1=aerial(exp_005), θ2=aerial→D2(exp_006)。

## 設計原則（これまでの議論で確定した「成立条件」）
1. **因果的 or 関係的**であること（絶対ドリフト量や「偶然当たるか」に依存しない）。
2. θ0/θ1 で**対応がとれる量**だけ使う（900クエリは非対応なので単体では使わない）。
3. **VLM検出固有**の切り口を優先。
4. 既存 ckpt で**再学習なし**に実行可能（重い学習は避ける／例外は明記）。

文献が収束している中心仮説（検証対象）: **「オープン語彙/VLMの忘却は主に vision–text アライメント界面で起きる」**
（COVD, SeGP-CL, COVD系）。ただし**DETR型・対照ヘッドの MM-GDINO では未検証** → 検証自体が貢献。

# Tier 1：忘却の「場所・性質」を特定する（θ0/θ1、再学習なし）

## P1. 因果的 stitching（活性パッチ＋重み巻き戻し）【採用済み・本命】
- **何を測る**: θ1 の特定部分を θ0 のもので置換し、COCO mAP の回復量で忘却を**因果的に局在**。
- **根拠**: activation patching / causal tracing、同一アーキ間は stitching（[2309.16042](https://arxiv.org/html/2309.16042v2)）。重み巻き戻し（[Reset It and Forget It, 2310.07996](https://arxiv.org/pdf/2310.07996)）。
- **MM-GDINOへの落とし込み**:
  - (A) 活性パッチ: `forward_encoder` 出力で、**`memory_text`(テキスト側)** または **`memory`(画像側)** を θ0 のものに差し替え（同一画像・同一プロンプト→トークン対応・形一致）。**クエリ埋め込みは非対応のため使わない**。
  - (B) 重み巻き戻し: `text_feat_map`／encoder fusion・text・image 層／decoder／`reg_branch` を個別に θ0 に戻して COCO 評価（デコーダは(A)で測れないので(B)担当。`reg_branch`単独戻し＝box寄与の分離）。
- **実行可能性**: フックで活性キャッシュ/注入、重み戻しは state_dict 操作、評価は既存 COCO eval。再学習なし。
- **VLM固有性**: memory↔memory_text の切り分け＝VLM検出器固有の vision/text 分解。中心仮説を因果検証。
- **分岐**: text側で回復→アライメント保護手法／image側→視覚保護／decoderのみ→相互作用。
- **caveat**: 活性パッチは十分性であり単独原因の証明でない（[interpretability illusion, 2311.17030](https://arxiv.org/pdf/2311.17030)）→ 双方向(θ0→θ1, θ1→θ0)＋(B)併用＋回復量を連続値で報告。注入の分布ズレ・非加法性は累積swapで補う。

## P2. 出力レベルの忘却分解（TIDE流）【観察の定量版】
- **何を測る**: COCO mAP 低下(θ0→θ1)を**誤りの種類**に分解：Miss(取りこぼし)/Cls(誤分類)/Loc(位置ずれ)/Bkg(幻覚)/Dupe。
- **根拠**: TIDE（[2008.08115](https://arxiv.org/pdf/2008.08115)）の6分類。
- **MM-GDINOへの落とし込み**: θ0/θ1 の最終予測(box・score・label)＋COCO GT に TIDE を適用し、**どの誤り種が θ0→θ1 で増えたか**を比較。`_predict_by_feat_single` の det_labels/scores をそのまま使える。
- **実行可能性**: 既存の予測出力＋GTのみ。tidecv 等で即実行。再学習なし。
- **VLM固有性**: 中（分解自体は検出一般）。ただし対照ヘッド上では「Miss/低score＝アライメント弱化」「Cls＝意味の取り違え」「Loc＝box劣化」と解釈でき、**先の50枚の定性観察（取りこぼし優勢・ラベル化けなし）を標準手法で定量検証**。
- **分岐**: Miss優勢→リコール/アライメント弱化（スコア較正）／Cls優勢→意味的混同／Loc優勢→box／Bkg→幻覚。各々で手法が変わる。
- **caveat**: 信頼度の動作点を固定する必要。TIDEのIoU閾値・マッチングは標準設定に従う。

## P3. 関係的アライメント幾何（前回壊れた①の正しい版）【VLM固有】
- **何を測る**: 「正しく局在した COCO 物体」に対する **クラス間アライメント・スコア構造** が θ0→θ1 でどう歪むか。
  指標: 正解クラスの (i) スコア絶対値、(ii) 競合クラスとの**マージン**、(iii) **順位**、(iv) 分布の拡散度。
- **根拠**: COVD（テキスト埋め込みドリフトを cosine＋**ペア関係行列**で測る）、SeGP-CL（[2603.12055](https://arxiv.org/abs/2603.12055)：「旧視覚パターンが新テキスト意味で"再解釈"される」＝アライメント回転）。
- **なぜ前回①は壊れ、今回は成立するか**: ①は `memory_text` の**絶対ドリフト**を測ろうとした→ query と text が同方向に回ると内積不変なので「ドリフト＝意味不明」だった。今回は**1物体に対するクラス間の相対構造（マージン/順位）**を測るので、共有回転に**不変**。
- **MM-GDINOへの落とし込み**: GT box に IoU 最大のクエリを対応づけ、その `cls_score`（`convert_grounding_to_cls_scores` 後のクラス別スコア）ベクトルを取得→ 物体×クラスのアライメント行列を θ0/θ1 で比較。
- **実行可能性**: COCO を forward しスコア行列を集計するだけ。再学習なし。
- **VLM固有性**: 高（対照アライメント構造そのもの）。
- **分岐**: マージン低下のみ(順位は保持)→アライメント**一様弱化**（較正）→スコア保護／正解が順位を失う→**意味的混同**→アンカー保護。
- **caveat**: クエリ対応は IoU 近似（忘却の判定でなく傾向把握に使う・分布で報告）。プロンプトは COCO 固定。

## P4. 表現の線形プローブ（表現崩壊 vs 読み出し上書き）【F3】
- **何を測る**: θ1 の**視覚表現**から COCO クラスが線形に復元できるか（θ0 と比較）。
- **根拠**: Probing Representation Forgetting（[Davari, CVPR2022, 2203.13381](https://arxiv.org/abs/2203.13381)）。表現の忘却と読み出しの忘却を分離。
- **MM-GDINOへの落とし込み**: encoder 出力 `memory`（多スケール画像トークン、`spatial_shapes`/`level_start_index` で格子位置既知）を GT box 内で pool → 領域特徴。これに線形プローブ(COCO分類)を θ0/θ1 別に学習し精度比較。
- **実行可能性**: 線形プローブの学習のみ（軽量）。
- **VLM固有性**: 中〜高。「表現は保たれ読み出し(=対照アライメント)が壊れた」を示せれば、忘却がアライメント側という仮説の独立証拠。
- **分岐**: 表現保持＆プローブ高精度→忘却は読み出し/アライメント／プローブ低下→視覚表現の崩壊。
- **caveat**: `memory` はプロンプト条件付き（固定して解釈）。分類が起きる**デコーダ・クエリの一歩手前**を見ている（P1/P3と相補）。

# Tier 2：どの「手法ファミリ」が効くかを事前判定する（やや重い／方法論寄り）

## P5. 重み補間バリア（線形モード接続性 / WiSE-FT の適用可否）【F4】
- **何を測る**: θ(α)=(1−α)θ0+αθ1 を数点で評価し、COCO と aerial の mAP 経路（バリア）を見る。
- **根拠**: LMC in CL（[2010.04495](https://arxiv.org/pdf/2010.04495)）、WiSE-FT（[2109.01903](https://arxiv.org/pdf/2109.01903)）。「補間で共有知識は保持・タスク固有知識は劣化」。
- **MM-GDINOへの落とし込み**: θ0/θ1 は**共有初期(θ0)を持つ同一アーキ**なので補間が定義可。backbone/BERT は同一なので学習部分のみ動く。α∈{0,.25,.5,.75,1} で COCO/aerial 評価。
- **実行可能性**: 重み平均＋評価のみ。再学習なし。
- **分岐**: 低バリア（中間で両方そこそこ）→**WiSE-FT/model-soup 型のマージがそのまま保持手法になる**（強力かつ単純なベースライン/手法）／高バリア→マージ単独では不可。
- **VLM固有性**: 低（だが手法選択に直結）。caveat: 補間は忘却対策の単独解にはならない（文献）。

## P6. 活性部分空間の重なり（主角度）【F2・exp_007 の自然な拡張】
- **何を測る**: COCO と aerial の**層ごと活性部分空間**(SVD)の重なり＝主角度。小さい角度（高重なり）＝高干渉。
- **根拠**: GPM（[2103.09762](https://arxiv.org/pdf/2103.09762)）、「Subspace Geometry Governs Forgetting in LoRA」（[2603.02224](https://arxiv.org/html/2603.02224)：**LoRA手法に直結**）。
- **MM-GDINOへの落とし込み**: COCO/aerial バッチを θ0 で forward、各 Linear 層の入力活性を収集→SVD→主角度。**exp_007 の Gram/部分空間解析の自然な続き**。
- **実行可能性**: 順伝播＋SVD のみ。再学習なし。
- **分岐**: どの層・経路で部分空間が重なるか→LoRA挿入箇所/直交制約の設計に直結（提案手法の根拠）。
- **VLM固有性**: 中。caveat: 重なり大は「忘却の予測子」であり不変則でない（非単調報告あり）。

# 推奨の進め方（優先順位）
1. **P2（TIDE分解）を最初に**：最軽量（予測＋GTのみ）で、忘却の「性質」を標準手法で確定。先の50枚観察を定量化し、以降の問いを規定する。
2. **P1（stitching）**：性質が分かった上で「場所」を因果的に特定（本命）。
3. **P3（関係アライメント幾何）/ P4（プローブ）**：P1の結論を独立な角度から裏取り（アライメント側 vs 視覚側）。
4. **P5/P6**：手法フェーズの設計判断用（マージ可否・LoRA挿入箇所）。

→ P2→P1 で「性質と場所」を押さえ、P3/P4 で裏取り、というのが最小で意味のある一直線。
