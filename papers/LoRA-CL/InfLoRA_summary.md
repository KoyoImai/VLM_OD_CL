# InfLoRA 要約（Interference-Free Low-Rank Adaptation for Continual Learning, CVPR2024）

出典: Liang & Li, Nanjing Univ. 本研究の提案手法（LoRA ベース継続学習）の方向性に最も近い参照。

## 一言で
事前学習モデルを凍結し、**LoRA 分岐の更新部分空間を「過去タスクの勾配空間と直交」かつ「新タスクの
勾配空間内」になるよう事前設計**することで、新タスク学習が過去タスクへ干渉しない（interference-free）
継続学習を実現する PEFT 手法。

## 設定
- PEFT ベース継続学習。事前学習 ViT を凍結し少数パラメータ（LoRA）のみ学習。
- **class-incremental・exemplar-free**（推論時タスクID不明・過去データ保存なし）。分類タスク。
- 比較対象: L2P / DualPrompt / CODA-P / C-LoRA / LAE。ImageNet-R, CIFAR100, DomainNet で SOTA。

## 手法の核
- LoRA: 線形層を `e = Wh + ABh`、W 凍結、A・B のみ学習（A は B∈R^{r×dI}, A∈R^{dO×r}）。
- **InfLoRA の肝**: 各タスク t の前に **次元削減行列 Bt を“設計”**（LoRA は通常 B をランダム初期化）。
  - **命題1**: B_t を固定して A_t のみ学習することは、**W を span{B_t の行} の部分空間内で fine-tune する**
    のと等価。→ B_t を選べば更新方向を制御できる。
  - **Bt の設計条件**: 更新部分空間が
    (a) **過去タスクの勾配空間 M_t と直交**（過去への干渉＝忘却を排除＝stability）、
    (b) **新タスクの勾配空間 N_t 内**（新タスクに集中＝plasticity）。
  - 実装: 新/旧タスクの勾配空間を **DualGPM** で近似・保持。N_t の M_t 直交成分 Ĥt を取り、SVD の
    上位 r 主成分で Bt を構成（式6-8）。
- **再パラメータ化（統合）**: タスク学習後に分岐を W へ統合（W_t = W_{t-1} + A_t B_t）。
  → **拡張パラメータはタスク数に依らず常に (dI+dO)r で一定**（メモリ非増加）。
- 学習目的は **local CE**（現タスクのクラスに限定した CE）。

## 主要結果（ImageNet-R, ACC↑）
- 20タスク: sequential 34.6 / CODA-P 67.3 / LAE 67.0 / **InfLoRA 71.0**。joint 上限 81.1。
- 過去タスク干渉の排除（直交制約）が stability-plasticity トレードオフを改善。

## 本プロジェクトへの適用と差分（重要）
- **方向性一致**: 「本体凍結＋LoRA＋過去への干渉を直交制約で排除」は、我々の知見
  （忘却源＝共有検出経路の上書き [[../../experiments/exp_004/outputs/notes]]）に直接対応する対策。
- **適用上の差分・課題**:
  1. **対象がViT分類**。MM-GDINO は backbone+言語+encoder+decoder+対照ヘッドの検出器
     → **どの線形層に LoRA を入れるか**は本研究の機序分析（モジュール局在化）で決める必要。
  2. **ゼロショット保持(ZCOCO)が追加目標**。InfLoRA の直交は「学習済み過去タスク」に対してのみ。
     本研究は **事前学習(ゼロショット/COCO)の勾配空間も“task-0”として直交対象に含める**拡張が要る（新規性候補）。
  3. **勾配空間推定(DualGPM)を検出損失で行う**必要（実装重め）。
  4. **domain-incremental**（タスクIDはクラス名プロンプトで実質与えられる）であり class-incremental と前提が異なる。
- → 本研究の手法(C3)は「InfLoRA を VLM 物体検出の継続学習＋ゼロショット保持へ拡張」する位置づけが有力。

## 機序分析(C2)への示唆
- InfLoRA の前提＝「共有パラメータの勾配空間で新旧タスクが干渉する」。
  本研究の機序分析は **この干渉が(どのモジュールで)実在することを示す**ことが、手法の動機付けになる:
  - 軸1（モジュール復元）で忘却源モジュールを特定 → LoRA 挿入箇所を決定。
  - 旧ドメイン/COCO と新ドメインの**勾配方向の重なり（干渉）**を測れば、InfLoRA の直交化が効く根拠になる。
