# TiROD 要約（Tiny Robotics Object Detection benchmark, 2024）

arXiv:2409.16215 (Pasti et al.)。**ドメイン増加型 継続物体検出に最も近いベンチマーク。**

## 中核
- ロボットが訓練分布から大きく**ドメインシフト**する設定を対象。
- **5環境10タスク**で **ドメイン増分(DIL)とクラス増分(CIL)を同時**に評価（Cross Domain シナリオ）。
- 継続物体検出を「新クラスや新データ分布で学習すると過去知識を失う破滅的忘却」として追跡。

## 本研究との関係
- 評価設定（ドメインシフト下の継続検出）は本研究と方向性が一致。ベンチマーク/指標設計の参考。
- **注意**: 純粋なドメイン増分でなく**クラス増分も同等に含む**ため、本研究の（RF100ドメイン中心の）設定とは部分的に異なる。
  → 本研究の「ドメイン増加＋ゼロショット(COCO)保持」ベンチマークの独自性を示す対比対象。
