# 実験2

## 位置付け
「問い2：新しいドメインの適応において学習が必要なモジュールはどこか」の1サイクル目．
実験1で「一部モジュールだけでは適応が不足」という判定を示した．
これを受けて，どのモジュールを学習すべきかという問い2の探索を行う．

## 目的
MM-Grounding DINOのモデルをモジュール分割する場合，

- Swin Transformer + neck：画像特徴の抽出
- BERT + text_feat_map：テキスト特徴の抽出
- feature enhancer：画像特徴とテキスト特徴の融合
- language guided query selection：クエリの選択
- cross modality decoder：クエリ-テキスト特徴-画像特徴の参照

という分類ができる．
これらを以下のように大きく分割する．

- 特徴抽出+融合：Swin Transformer + neck + BERT + text_feat_ma + feature enhancer
- 下流：language guided query selection + cross modality decoder

「特徴抽出+融合」と「下流」のどちらに新ドメインの適応に重要なモジュールが含まれているかを探索する．


## 仮説
各ドメインは，新ドメインに適応に異なる影響を与える．
特に，Roboflow100の各ドメインに含まれるデータは，事前学習データには含まれない画像やテキストを持つため，有効な特徴抽出や融合ができない可能性が高い．
（探索がメインのため，仮説に重きは置かない．）


## 条件
- 条件0：ゼロショット（事前学習済みパラメータを固定して使用）
- 条件1：特徴抽出+融合部分（Swin Transformer + neck + BERT + text_feat_ma + feature enhancer）のみ学習
- 条件2：下流部分（language guided query selection + cross modality decoder）のみ学習
- 条件3：unfrozen（MM-Grounding DINOの全てのモジュールを学習する方式）
- データセット：Roboflow100を用いて単一ドメインでのみ学習
- 評価：適応ドメインの mAP と COCO2017 のゼロショット mAP

## 判定基準
全モジュールを学習可能にする条件3と比較して，性能低下が0.05以内であれば適応可能として判定する．

## 判定
条件1では，underwater（-0.004），videogame（-0.005），electromagnetic（-0.017）全てで性能低下が0.05以内であるため，適応可能である．

条件2では，underwater（-0.15），videogame（-0.437），electromagnetic（-0.205）全てで性能低下が0.05以上となっているため，適応困難である．

## 考察

### 主要結果の要約
条件1の学習評価結果は，条件3（フルファインチューニング）と同等の適応性能とCOCO2017の性能維持を達成する．
一方で条件2は，条件1や条件3と比較しててこうドメインの性能が低下し，さらにCOCO2017の性能も低下している．
