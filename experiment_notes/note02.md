# 実験2

## 位置付け
「問い2：新しいドメインの適応において学習が必要なモジュールはどこか」の1サイクル目．
実験1で「一部モジュールだけでは適応が不足」という判定を示した．
これを受けて，どのモジュールを学習すべきかという問い2の検証を行う．

## 目的
MM-Grounding DINOのモデルをモジュール分割する場合，

- Swin Transformer + neck：画像特徴の抽出
- BERT + text_feat_map：テキスト特徴の抽出
- feature enhancer：画像特徴とテキスト特徴の融合
- language guided query selection：クエリの選択
- cross modality decoder：クエリ-テキスト特徴-画像特徴の参照

という分類ができる．
これらを以下のように大きく分割する．

- 特徴抽出+融合（条件A）：Swin Transformer + neck + BERT + text_feat_map + feature enhancer
- 下流（条件B）：language guided query selection + cross modality decoder

「特徴抽出+融合」と「下流」のどちらに新ドメインの適応に重要なモジュールが含まれているかを探索する．


## 実験種別
仮説検証

## 仮説
各モジュールは，新ドメインへの適応に異なる影響を与える．
特に，Roboflow100の各ドメインに含まれるデータは，事前学習データには含まれない画像やテキストを持つため，有効な特徴抽出や融合ができない可能性が高い．
そのため，特徴抽出・融合を担うモジュールを学習可能にした条件Aは，フルファインチューニング（条件3）と同等の適応性能を達成する．
一方で，特徴抽出・融合を凍結し下流部のみを学習可能にした条件Bは，条件3と同等の適応性能には達しない．



## 条件
- 条件0：ゼロショット（事前学習済みパラメータを固定して使用）
- 条件A：特徴抽出+融合部分（Swin Transformer + neck + BERT + text_feat_map + feature enhancer）のみ学習
- 条件B：下流部分（language guided query selection + cross modality decoder）のみ学習
- 条件3：unfrozen（MM-Grounding DINOの全てのモジュールを学習する方式）
- データセット：Roboflow100を用いて単一ドメインでのみ学習
- 評価：適応ドメインの mAP と COCO2017 のゼロショット mAP．判定は適応ドメインのみで，観察用にCOCO2017のゼロショット性能も測る．

## 判定基準
全モジュールを学習可能にする条件3と比較して，性能低下が0.05以内であれば適応可能として判定する．

## 結果

### 適応ドメイン
|      | underwater | videogame | electromagnetic |
|------|------------|-----------|-----------------|
| 条件0 | 0.051      | 0.016     | 0.024           |
| 条件A | 0.355      | 0.777     | 0.485           |
| 条件B | 0.209      | 0.345     | 0.297           |
| 条件3 | 0.359      | 0.782     | 0.502           |

### COCO2017
|      | underwater | videogame | electromagnetic |
|------|------------|-----------|-----------------|
| 条件0 | 0.504      | 0.504     | 0.504           |
| 条件A | 0.411      | 0.328     | 0.279           |
| 条件B | 0.373      | 0.143     | 0.304           |
| 条件3 | 0.407      | 0.315     | 0.269           |


## 判定
条件Aでは，underwater（-0.004），videogame（-0.005），electromagnetic（-0.017）全てで性能低下が0.05以内であるため，適応可能である．

条件Bでは，underwater（-0.15），videogame（-0.437），electromagnetic（-0.205）全てで性能低下が0.05以上となっているため，適応困難である．

## 考察

### 主要結果の要約
適応ドメインの mAP について，条件Aと条件3（フルファインチューニング）の差は underwater が-0.004，videogames が -0.005，electromagnetic が -0.017 で，3ドメインとも 0.05 以内に収まる．
一方で条件Bと条件3の差は，-0.150，-0.437，-0.205で，いずれも0.05を大きく超える低下を示す．

また，条件Bの適応ドメインのmAPは，(0.209，0.345，0.297)と条件0（ゼロショット）の（0.051，0.016，0.024）を大きく上回るため，適応不足は学習が進んでいないことによるものではない．

観察指標のCOCO2017に注目する．
条件Aは（0.411，0.328，0.279）で，条件3の（0.407，0.315，0.269）と同程度である．
適応ドメインの mAP と同様に，COCO2017でも同程度の精度に達している．
しかし，条件0と比較すると低下があり，忘却の発生が確認できる．

条件Bは（0.373，0.143，0.304）で，ドメインごとにばらつきが発生し，underwaterとvideogamesは条件3と条件Aより低く，特にvideogamesは条件3の0.315よりも大きく下回る．
条件Bの学習可能パラメータは 12.29M（全体の 7.1%）で，条件3の 172.92M の 1/14 と学習可能パラメータが圧倒的に少ない状態で，適応が低いにもかかわらず，忘却は条件3よりも大きい．


### 結果からの示唆
- 適応十分性の主張：特徴抽出・融合部を学習可能にするだけで，フルファインチューニング（条件3）と同等の適応能力を示す．
- 適応不足の主張：下流部分だけ学習しても，フルファインチューニングとの差が（-0.150，-0.437，-0.205）と大きく，適応が不足することを示す．

上記2つの結果より，下流部分（クエリ選択とデコーダ）は事前学習状態のまま凍結していても適応は進み，新ドメインの適応に必要な学習は下流に存在しない可能性がある．

- 忘却についての示唆1：条件A（特徴抽出・融合部のみ学習）は，条件3（フルファインチューニング）と同程度の適応能力を示すが，COCO2017の精度も条件3と同程度まで低下する．つまり，適応を担うモジュールを学習することで忘却を発生している．
- 忘却についての示唆2：条件B（下流部のみ学習）は，学習可能パラメータが 12.29M と条件3（フルファインチューニング）の 1/14 しかなく，適応性能も条件3に遠く及ばないにも関わらず，条件Aや条件3と比較して underwater と videogames で COCO2017 の性能が低下する．

上記2つの結果より，忘却量は学習可能パラメータや適応能力で決定するのではなく，学習可能なモジュールに依存する可能性がある．

### 解釈の根拠
条件0，条件3，条件A，条件Bの違いは，学習可能なモジュールの差のみに依存しており，学習率やバッチサイズ，エポック数などのハイパーパラメータは全て共通の設定としている．
条件Aと条件Bの学習可能モジュールの学習率は，条件3と同じ設定である．

条件Aと条件Bの分割は，排他的かつ網羅的である．
条件Aと条件Bそれぞれの学習可能モジュールを統合することで，条件3のフルファインチューニングと同じモデル構造となる．
各条件で重複するモジュールが存在しないため，各条件での結果がいずれかのモジュールに寄与する．
そのため，条件Aで到達可能な適応能力はA側のモジュールの働き，条件Bで到達しなかった適応能力についてはB側だけでは足りないことに帰属する．

### 代替説明
- パラメータ量による説明：条件A（160.64 M）と条件B（12.29 M）には13倍程度の学習可能パラメータ数の差が存在する．そのため，条件Bの適応能力不足は，学習可能なパラメータ数によるものという説明が立つ．しかし，note01において，条件2（language model + text_feat_map）はBERTを学習することで 109.09 M のパラメータを学習したにも関わらず，条件Bよりも新ドメインの適応能力に劣っている．よって，パラメータの量による説明は成り立たない．
- 最適化の不足：学習終盤において，条件Aは underwater が16エポック以降 0.351~0.355，videogamesが0.770~0.777，electromagneticが0.479~0.485と変動が0.005前後で収まる．条件Bも同様にunderwaterが0.206~0.209，electromagneticが0.282~0.297と平坦である．条件Bのvideogamesだけは終盤でも0.288~0.345と上昇が見られるが，条件3に届く伸びを見せる程度ではないため，可能性としては弱い．
- 単一seed：1seedのみでの実行であるため，別のseed値で結果が変動する場合もありうるが，可能性は低い．


### この実験から言えること
- 特徴抽出・融合部のみを学習（条件A）すれば，フルファインチューニングと同等の適応が達成できる．逆に下流部のみの学習（条件B）では，フルファインチューニングと同等の適応を達成できない．
- 適応能力の決めるのは学習可能なパラメータの量ではなく，学習可能なモジュールである．note01の条件2の適応能力（109.09M，0.185/0.315/0.215）がnote02の条件Bの適応能力（12.29M，0.209/0.345/0.297）に劣ることから証明可能である．
- 適応を担う箇所（条件A）を学習すると，忘却も条件3と同じ規模で発生する．そのため，学習箇所を絞るだけでは忘却の抑制が難しい．


### この実験から言えないこと
- 条件Aの広さ：条件Aでの学習の適応能力が向上した原因について，パラメータの量が原因ではないことは，これまでの確認でわかっている．しかし，特徴抽出・融合部の全体が適応に必要かについては，特徴抽出モジュールと融合モジュールの細分化を行っていたいため不明である．条件Aに含まれる複数のモジュールのうち，一部のモジュールだけでも同様の適応能力を示す可能性がある．


## 次に確認すること
- 条件Aの細分化：実験2では「特徴抽出+融合部」と「下流部」という大きな括りでのみ学習・固定を行った．その結果，「特徴抽出+融合部」というモジュール群が適応能力の向上に重要であることがわかった．しかし，「特徴抽出+融合部」に含まれる全てのモジュールが重要か，それとも，テキストエンコーダや画像テンコーダ，Feature Enhancerのいずれかが重要かは不明である．そのため，より「特徴抽出+融合部」を細分化し，どのモジュールが適応を担うかを調査する．\
既存の実験は，この細分の一部にすでに答えている．実験1の条件1（neck + text_feat_map，2.31 M）は 0.208/0.113/0.222，条件2（BERT + text_feat_map，109.09 M）は 0.185/0.315/0.215 であり，いずれも条件3に遠く及ばない．どちらも「特徴抽出+融合部」の部分集合であり，特徴抽出に属する．すなわち，特徴抽出側の一部のみでは適応が不足することはすでに蓋通りで確認されている．
