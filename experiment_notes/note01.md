# 実験1

## 位置付け
「問い1：既存手法はドメインへの新しい適応が困難か？」の調査．
手法そのものを学習・評価するのではなく，正則化やAdapterを取り除き，適応能力の上限を測定する．

## 目的
既存手法が学習可能にするモジュール箇所を正則化なしで更新し，適応性能の上限を測る．
ZiRa のようなAdapter型の追加パラメータは，元モデルへの併合可能なため，同じ箇所の学習更新で適応上限を測定可能である．
また，COVD (NoIn-Det)のように，一部のモジュールを知識蒸留による正則化を行いながら新しいタスクで更新する場合においても，知識蒸留による正則化を取り除き新しいドメインで更新を行うことで，新ドメインへの適応上限を測定可能である．

## 実験方針
仮説検証

## 仮説
一部モジュールのみ学習可能な状態では，専門的なドメインを学習した場合において，新ドメインへのmAPが全モジュールを学習するフルファインチューニングよりも大きく低下する．

## 条件
- 条件0：ゼロショット（事前学習済みパラメータを固定して使用）
- 条件1：Neck + text_feat_map のみ学習する（ZiRa方式）
- 条件2：language_model + text_feat_map（NoIn-Det方式）
- 条件3：unfrozen（MM-Grounding DINOの全てのモジュールを学習する方式）
- データセット：Roboflow100を用いて単一ドメインでのみ学習
- 評価：適応ドメインの mAP と COCO2017 のゼロショット mAP．判定は適応ドメインのみで，観察用にCOCO2017のゼロショット性能も測る．

## 判定基準
条件1と条件2における適応ドメインの mAP X が条件3での mAP Y と比較して「X < Y-0.05」なら適応不足とい判定する．

## 判定
条件1と条件2の両方において，新しいドメインへの適応が困難である．

## 考察

### 主要結果の要約
条件1と条件2は，適応ドメインの検出性能が条件0（ゼロショット）よりも高く，新しいドメインの学習が行えている，
しかし，条件3（フルファインチューニング）よりも性能が著しく低下しており，underwater，videogame，electromagneticそれぞれについて，条件1は（-0.151 / -0.669 / -0.280），条件2は（-0.174 / -0.467 / -0.287）だけ mAP が低下しており，適応能力が低いことがわかる．

また，ドメインによって条件1と条件2の適応 mAP に差が発生する．
underwaterとelectromagneticは，条件1と条件2の比較において同程度，あるいは条件2が僅かに下回るという結果であるのに対して，videogameドメインのみ条件2が条件1を大きく上回る結果となっている．

### 結果からの示唆
条件1と条件2のCOCO2017の検出性能は，条件3（フルファインチューニング）と比較して高く，学習モジュールを制約することで忘却抑制が可能であり，新ドメインへの適応と事前学習した知識の維持はトレードオフになる可能性がある．
