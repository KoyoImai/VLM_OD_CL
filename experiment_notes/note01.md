# 実験1

## 位置付け
「問い1：既存手法はドメインへの新しい適応が困難か？」の調査．
手法そのものを学習・評価するのではなく，正則化やAdapterを取り除き，適応能力の上限を測定する．

## 目的
既存手法が学習可能にするモジュール箇所を正則化なしで更新し，適応性能の上限を測る．
ZiRa のようなAdapter型の追加パラメータは，元モデルへの併合可能なため，同じ箇所の学習更新で適応上限を測定可能である．
また，COVD (NoIn-Det)のように，一部のモジュールを知識蒸留による正則化を行いながら新しいタスクで更新する場合においても，知識蒸留による正則化を取り除き新しいドメインで更新を行うことで，新ドメインへの適応上限を測定可能である．

## 実験方針
仮説検証

## 仮説
一部モジュールのみ学習可能な状態では，専門的なドメインを学習した場合において，新ドメインへのmAPが全モジュールを学習するフルファインチューニングよりも大きく低下する．

## 条件
- 条件0：ゼロショット（事前学習済みパラメータを固定して使用）
- 条件1：Neck + text_feat_map のみ学習する（ZiRa方式）
- 条件2：language_model + text_feat_map（NoIn-Det方式）
- 条件3：unfrozen（MM-Grounding DINOの全てのモジュールを学習する方式）
- データセット：Roboflow100を用いて単一ドメインでのみ学習
- 評価：適応ドメインの mAP と COCO2017 のゼロショット mAP．判定は適応ドメインのみで，観察用にCOCO2017のゼロショット性能も測る．

## 判定基準
条件1と条件2における適応ドメインの mAP X が条件3での mAP Y と比較して「X < Y-0.05」なら適応不足と判定する．

## 結果

### 適応ドメイン
|      | underwater | videogame | electromagnetic |
|------|------------|-----------|-----------------|
| 条件0 | 0.051      | 0.016     | 0.024           |
| 条件1 | 0.208      | 0.113     | 0.222           |
| 条件2 | 0.185      | 0.315     | 0.215           |
| 条件3 | 0.359      | 0.782     | 0.502           |

### COCO2017
|      | underwater | videogame | electromagnetic |
|------|------------|-----------|-----------------|
| 条件0 | 0.504      | 0.504     | 0.504           |
| 条件1 | 0.465      | 0.462     | 0.447           |
| 条件2 | 0.489      | 0.443     | 0.443           |
| 条件3 | 0.407      | 0.315     | 0.269           |


## 判定
条件1と条件2の両方において，新しいドメインへの適応が困難である．

## 考察

### 主要結果の要約
条件1と条件2は，適応ドメインの検出性能が条件0（ゼロショット）よりも高く，新しいドメインの学習が行えている，
しかし，条件3（フルファインチューニング）よりも性能が著しく低下しており，underwater，videogame，electromagneticそれぞれについて，条件1は（-0.151 / -0.669 / -0.280），条件2は（-0.174 / -0.467 / -0.287）だけ mAP が低下しており，適応能力が低いことがわかる．

また，ドメインによって条件1と条件2の適応 mAP に差が発生する．
underwaterとelectromagneticは，条件1と条件2の比較において同程度，あるいは条件2が僅かに下回るという結果であるのに対して，videogameドメインのみ条件2が条件1を大きく上回る結果となっている．

COCO2017 の mAP は事前に判定基準を設定していないため，以下は観察として記述する．
COCO2017 の mAP を比較すると，条件3と比較して条件1と条件2は，条件0からの検出性能の低下を抑制している．
ただし，条件0からの低下があるため，忘却は発生している．

### 結果からの示唆
結果より，条件1と条件2の新ドメインでの学習はできている．
しかし，条件3（フルファインチューニング）からの低下が 0.151 ~ 0.669 で，判定基準とした 0.05 を大きく上回る低下を見せた．
条件1と条件2は，正則化項やAdapterなどを用いず，各モジュールを学習することで得られる適応能力の上限を測定している．
そのため，学習モジュールを変更せず，そのモジュールのみを学習する場合において正則化を弱くする，Adapterのサイズを大きくするといった実装側の改良では適応不足が解消されない．
したがって，新ドメインの適応不足は，学習箇所の選択に帰属し，どのモジュールを学習すべきかという問いが必要になる．

### 解釈の根拠
条件0〜条件3の違いは，学習可能なモジュールの差のみに依存しており，学習率やバッチサイズ，エポック数などのハイパーパラメータは全て共通の設定としている．
条件1と条件2の学習可能モジュールの学習率は，条件3と同じ設定である．

また，従来手法 ZiRa の RDB は，元の重みにマージ可能な線形の並列 Adapter であるため，RDB が表現できる更新は，同じ層の重みを直接更新して到達できる更新の部分集合である．
したがって，同じ箇所を正則化なしで直接更新した条件1は，ZiRaが到達しうる適応性能の上限になる，
同様に，従来手法 NoIn-Det (COVD) の知識蒸留は更新を制約する正則化であるため，これを外した条件2も同様に適応の上限となる．

したがって，観測された性能差は，学習モジュールの違い以外に帰属しない．

### 代替説明
- 最適化の不足：学習エポック数や最適化のハイパーパラメータは，全ての条件で統一しているが，学習パラメータ数の少ない条件1と条件2では，学習が不足する可能性がある．損失推移や検出精度などの学習曲線を確認したところ，条件1は学習の終盤でほとんど値が平坦であり排除できる．条件のvideogameのみ20エポック目でも精度が上昇中であったが，傾きの大きさより条件3との性能差を埋めるだけの説明はできない．
- 学習可能なパラメータ数の低下：条件ごとの差は，学習可能なモジュールだけでなく，学習可能なパラメータ数の違いも発生する．そのため，学習可能なパラメータ数が減少したことで，新ドメインへの適応が不足した可能性が考えられる．ただし，条件2はテキストエンコーダのBERT（108.89M）を学習しており，条件1は（2.31M），条件3は（172.92M）である．条件2は条件1の約47倍のパラメータを学習可能にしているにも関わらず，新ドメインへの適応が同程度であることから，学習可能なパラメータ数である可能性は低い．
- 単一 seed：今回の実験は seed=0 のみで行なっており，他のseed値では行なっていない．そのため，別のseedでは異なる結果がでる可能性がある．しかし，条件3との間に存在する適応能力の不足は，seed値の違いによる差としては大きすぎるため，可能性は低い．

### この実験から言えること
条件1と条件2は既存手法が学習可能にしているモジュールを，正則化やAdapterを除外して直接学習しても，3ドメイン全てで条件3に対する適応不足となる．このことから，適応不足は，学習を止めたモジュールがあることに起因する．

### この実験から言えないこと
適応不足の原因は，一部モジュールを止めたことに起因するが，その本質が「モジュールの特性・役割」と「モジュールのパラメータ数」のどちらにあるかはわからない．

## 次に確認すること
本実験は，既存手法が学習可能にしているモジュールでは新ドメインへの適応が不足するという結果を示した．
しかし，どのモジュールを学習すれば適応が足りるかについては明らかにしていない．
したがって次は，MM-Grounding DINOのモジュールを役割で分割し，どの部分が新ドメインの適応を担っているかを調査する．
