# Research Question
事前学習済み Vision Language Model の物体検出器を，事前学習データセットと大きく異なるドメインへ逐次適応（継続学習）させるとき，適応と知識維持の両立はどのようなアプローチ（条件）で達成できるか．

# 研究背景と既存研究の問題点
近年の物体検出は，大規模な事前学習データセットで学習した　Vision Language Model (VLM) によって，高い検出性能を達成している．これらの物体検出器は，COCOなどの一般物体検出において高いゼロショット検出性能を達成可能いである．この高い汎化性能に着目し，物体検出継続学習においても，大規模な事前学習を行なった VLM 物体検出器を導入している．
従来手法の ZiRa や DitHub，NoIn-Det（COVD）は，事前学習済み VLM 物体検出器を初期パラメータとして使用し，追加の小規模な Adapter や LoRA を導入し，事前学習済みパラメータ大部分，あるいは全てのパラメータを固定して新しい知識を獲得する．このように，事前学習済みパラメータの大部分を固定することで，事前学習で獲得した知識を保持し，さらに追加の小規模な Adapter で学習を制約することで，事前学習で獲得した知識と新しく逐次学習した知識の忘却を抑制する．

しかし，従来の VLM 物体検出継続学習は，事前学種データセットとドメインが大きく変化する環境を想定していない．
実世界に展開する物体検出器は，事前学習で獲得した一般ドメインに関する知識に加えて，水中ドメインや医療ドメインなど，より専門的なドメインに関する画像での物体検出能力が求められる．
従来研究は，ODinW-13ベンチマークの逐次学習によって継続学習能力を測定しているが，ODinW-13にはこうした専門的なドメインを十分に含んでおらず，microscopic や documents などのデータは含まれない．そのため，従来のベンチマークでは，事前学習の想定から外れた専門ドメインへの適応能力と，過去に学習した知識の維持能力を測定することがてきない．

そこで，本研究では，まず RoboFlow100 を用いた新しい VLM 物体検出継続学習ベンチマークを構築する．
RoboFlow100は，underwater や electromagnetic，videogames といった事前学習データセットには含まれない専門的ドメインが含まれている．
提案するベンチマークは，ROboflow100 に含まれるデータを underwater，aerial，videogames，electromagnetic，documents，microscopics の6つのドメインに分割する．
その後，これら6つのドメインを順番に連結し，事前学習済みモデルを逐次的に学習する．
これにより，モデルが新しいドメインの知識を逐次的に学習しながら，過去に学習した知識や事前学習で獲得した汎用的な知識を維持可能かを測定する．

構築したベンチマークで従来手法を学習・評価すると，新しいドメインの知識の獲得が困難であることがわかった．
継続学習的アプローチを一切使用しないフルファインチューニングと従来手法のZiRaやDitHubをRoboflow100の同一ドメインで学習した際，フルファインチューニングと比較して従来手法の検出精度が著しく制限される．
さらに，専門的なドメインを逐次的に学習する場合，従来手法は過去に学習したドメインの知識が消失する破滅的忘却が発生する．

## 本研究で提案する手法の方向性
既存研究は 小規模な Adapter や LoRA の追加，事前学習済みパラメータの固定という方向性で発展している．一方で，過去に学習したデータリプレイするリプレイベースのアプローチについては発展されていない．
そこで本研究では，VLM 物体検出継続学習におけるリプレイベースアプローチの有効性を初めて調査する．


## 問い1：既存手法はドメインへの新しい適応が困難か？
既存のVLM物体検出継続学習手法は，モジュールの大部分を事前学習済みパラメータで固定し，ごく一部の限られたモジュールや追加Adapterを学習する．
このとき，事前学習データと大きく異なるドメイン（Roboflow100に含まれる6つのドメイン）で学習する場合，新しいドメインに適応可能か？

## 問い2：新しいドメインの適応において学習が必要なモジュールはどこか
一部のモジュールだけ学習すると，新しいドメインへの適応が困難になり，全てのモジュールを学習可能にするフルファインチューニング（unfrozen）と比較して，新ドメインでの検出性能が低下する．
このとき，学習すべきは全てのモジュールなのか，それとも一部のモジュールだけ学習することで，フルファインチューニングと同等の性能を達成できるのか？
